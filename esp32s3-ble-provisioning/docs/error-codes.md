# Error Codes

| code | name | description |
|---|---|---|
| 0 | OK | 成功 |
| 1001 | BLE_CONNECT_FAILED | BLE 连接失败 |
| 1002 | SECURITY_FAILED | 安全握手失败 |
| 1003 | INVALID_POP | PoP 错误 |
| 2001 | WIFI_AP_NOT_FOUND | 未找到 AP |
| 2002 | WIFI_AUTH_FAILED | Wi-Fi 鉴权失败 |
| 2003 | WIFI_CONNECT_TIMEOUT | Wi-Fi 连接超时 |
| 2004 | DHCP_TIMEOUT | DHCP 超时 |
| 3001 | CUSTOM_DATA_INVALID | 自定义数据非法 |
| 3002 | TOKEN_EXPIRED | token 过期 |
| 4001 | DEVICE_ALREADY_PROVISIONED | 设备已配网 |
| 5001 | UNKNOWN_ERROR | 未知错误 |

要求：固件日志、Python CLI、Android UI 共用本表。
